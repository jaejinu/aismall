# D 결정 (2026-10-04, 사용자: 권장안 전부 승인 "좋아 고고")
- D-01 (b) 회원의 '관리자 확인' 신청은 예약 목록 '승인 대기' 탭 + 예약 상세가 정본. Today 카드·모바일 푸시로 진입. 승인함(Approvals)은 AI 제안 전용.
- D-02 (a) 관리자 확인 프로그램에서 회차 이동 시 다시 승인 대기, 기존 예약은 승인될 때까지 유지.
- D-03 (a) AI 문의 기반 예약 제안은 승인 대기 중 자리를 잡지 않음. 승인 시 잔여석 없으면 Conflict + 대체 회차.
- D-04 (b) 대기 신청 시 '자리 나면 자동 확정' 동의 기본값 꺼짐(회원이 직접 체크). 자동 확정 후 1시간 취소 허용.
- D-05 (a) 오버부킹·다가오는 예약 수 제한·노쇼 반복 제한은 v1에 없음(기록만).
- D-06 (a) 자동 실행은 LOW만. 같은 회차·같은 유형 MEDIUM은 묶음 카드로 한 번에 승인(개별 제외 체크).

- D-08 (a) Guardrail 차단·Flagged 즉시 알림 대상: 해당 지점 오너 + 최고관리자. 고객 처리가 멈춘 건만 방해 금지 중에도 푸시, 나머지는 인앱 즉시.
- D-09 (a) 직원은 배정 지점 실무자이며 관리 레벨이 아님(이전 결정 '직원 ⊂ 중간관리자' 문구 수정). 라우팅에서 지정하지 않으면 승인 불가. 회원 신청 확정 권한은 B-01에서 옵션으로.
- D-10 (b) AI 권한은 브랜드 기본값 + 지점별로 좁히기만 허용.
